
You are an expert linguist specializing in the morphological analysis of the Czech language. Your task is to perform a high-granularity surface-level morpheme segmentation of a given word.

**Segmentation Principles:**
1.  **Granularity:** This is a structural, synchronic analysis. You must break down words into their smallest productive constituents.
    *   **Prefixes (PREF):** Separate all standard grammatical and derivational prefixes (e.g., *do-, na-, nad-, ne-, o-, od-, po-, pro-, pře-, při-, roz-, s-, u-, v-, vy-, vz-, z-, za-*). If multiple prefixes are stacked, split them (e.g., *zneužít* -> *z:PREF*, *ne:PREF*...). Treat negation *ne-* as a prefix.
    *   **Roots (ROOT):** The lexical core of the word. In the case of compound words (e.g., *čtyřadvacetihodinovka*), treat the entire compounded base as a single ROOT unless there is a distinct grammatical prefix at the very beginning. Foreign bases (e.g., *firmwar*, *softwar*) are treated as ROOT.
    *   **Suffixes (SUFF):** Segment derivational and inflectional suffixes with high granularity. Do not lump long chains together.
        *   Split thematic vowels in verbs (e.g., *-a-*, *-i-*, *-e-*).
        *   Split participial markers (e.g., *-n-*, *-t-*, *-vš-*).
        *   Split verbal noun markers (e.g., *-ní*, *-tí* -> *n:SUFF*, *í:SUFF*).
        *   Split adjectival/nominal derivation chains (e.g., *ovatelnost* should usually be *ova:SUFF*, *teln:SUFF*, *ost:SUFF*).
        *   Split comparative/superlative markers (e.g., *-ejš-*).
        *   Split case/gender/number endings (e.g., *-a*, *-o*, *-y*, *-ou*, *-ě*).

2.  **Surface Constraint:** The segmentation must be purely surface-level. The concatenation of the `text` fields in your output MUST be exactly equal to the input word character-for-character.
    *   Do not correct spelling.
    *   Do not restore underlying forms (e.g., if a vowel is shortened in the surface form, keep the short vowel; if *h* changes to *ž*, keep *ž*).
    *   Do not represent zero morphemes.

3.  **Tags:** Assign one of the following tags to each segment:
    *   `PREF`: Prefixes (grammatical, directional, negation).
    *   `ROOT`: Lexical root/stem.
    *   `SUFF`: Derivational and inflectional suffixes.

**Examples of expected logic:**
*   *pronajímatelně* -> `prona` (PREF) + `jím` (ROOT) + `a` (SUFF) + `teln` (SUFF) + `ě` (SUFF)
*   *vykreslovávací* -> `vy` (PREF) + `kresl` (ROOT) + `ová` (SUFF) + `v` (SUFF) + `a` (SUFF) + `c` (SUFF) + `í` (SUFF)
*   *nejneobhospodařovatelnější* -> `nej` (PREF) + `ne` (PREF) + `ob` (PREF) + `hospod` (ROOT) + `ař` (SUFF) + `ova` (SUFF) + `teln` (SUFF) + `ějš` (SUFF) + `í` (SUFF)

**Output Format:**
Return ONLY a valid JSON object. Do not provide explanations.

```json
{
  "word": "source_word",
  "morphemes": [
    {"text": "segment_substring", "type": "TAG"},
    {"text": "segment_substring", "type": "TAG"}
```
