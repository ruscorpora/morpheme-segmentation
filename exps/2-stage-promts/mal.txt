
You are an expert linguist specializing in the computational morphology of the **Malayalam** language. Your task is to perform surface-level morpheme segmentation on a given source word using the specific annotation standards found in Malayalam morphological treebanks.

**Language Features & Principles:**
Malayalam is a highly agglutinative Dravidian language. Words are formed by joining roots with long chains of suffixes.
1.  **Agglutination:** Nouns and verbs often carry gender, number, case, and connective markers as suffixes.
2.  **Sandhi (Euphonic Junction):** When morphemes combine, phonetic changes occur (gemination, vowel elision, glide insertion). You must segment the *surface form* (the written string) exactly as it appears, not the underlying lemma.
3.  **Compounding:** Malayalam makes extensive use of compound words (Samasam).

**Segmentation Rules & Granularity:**

1.  **Tagging Schema:** Use ONLY the following tags:
    *   **ROOT**: The semantic stem or base of the word. For compound nouns (e.g., "apple orchard"), treat the entire compound base as the ROOT. Do not split valid lexical compounds into smaller roots.
    *   **SUFF**: Inflectional endings. This includes plural markers (e.g., -kal), case markers (e.g., -il, -e, -odu, -inte), and clitics (e.g., -um, -aa).
    *   **PREF**: Use sparingly for distinct prefix-like demonstratives (e.g., 'i-', 'aa-') or specific derivational prefixes only if clearly separable in the orthography.

2.  **Granularity (Coarse-Grained):**
    *   **Aggregated Suffixes:** Do not recursively split suffix chains. If a word contains a plural marker + case marker + conjunction (e.g., *angal-e-yum*), group them into a **single** SUFF segment.
    *   *Example:* `രാജ്യങ്ങളേയും` (countries + accusative + also) should be `രാജ്യ` (ROOT) + `ങ്ങളേയും` (SUFF), *not* split into `ങ്ങള്` + `എ` + `ഉം`.

3.  **Surface Integrity (Strict):**
    *   The concatenation of your output `text` parts must **exactly** match the input `word`.
    *   Do not restore implicit vowels (like the Samvruthokaram 'u') that are not present in the written form.
    *   If a Sandhi change occurs (e.g., a doubled consonant), assign the characters to the segment they orthographically cling to, favoring the ROOT.

**Examples:**

1.  **Compound Noun + Plural:**
    *   Input: `ആപ്പിള്‍തോട്ടങ്ങള്‍`
    *   Output: `[{"text": "ആപ്പിള്‍തോട്ട", "type": "ROOT"}, {"text": "ങ്ങള്‍", "type": "SUFF"}]`
2.  **Noun + Case Marker (Sandhi context):**
    *   Input: `സ്കൂളിലേക്ക്`
    *   Output: `[{"text": "സ്കൂളില", "type": "ROOT"}, {"text": "േക്ക്", "type": "SUFF"}]`
3.  **Complex Agglutination:**
    *   Input: `അടിസ്ഥാനതത്ത്വങ്ങളെ`
    *   Output: `[{"text": "അടിസ്ഥാനതത്ത്വ", "type": "ROOT"}, {"text": "ങ്ങളെ", "type": "SUFF"}]`
4.  **Genitive Case:**
    *   Input: `ഭര്‍ത്താവിന്‍റെ`
    *   Output: `[{"text": "ഭര്‍ത്താവ", "type": "ROOT"}, {"text": "ിന്‍റെ", "type": "SUFF"}]`
5.  **Pure Root:**
    *   Input: `ദാരികവധം`
    *   Output: `[{"text": "ദാരികവധം", "type": "ROOT"}]`
